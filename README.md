# NoteVibe - オンラインMIDI共有＆ストリーミング再生Webアプリ

**NoteVibe** は、GitHub Pages だけでホスト・実行できるオンライン専用のMIDI共有＆再生プラットフォームです。  
`.mid` / `.midi` ファイルの選択・ブラウザ内作成、作成者限定のメタデータ設定書き込み、オンライン全体公開、いいね・コメント反応・セーブ機能を備えています。

---

## 主な機能

1. **オンライン専用動作（ネットワーク必須）**
   - インターネット接続が切れると自動的にオフラインロック画面が表示され、ネットワーク環境下でのみ再生・公開・同期が動作します。
   - 分散リアルタイム同期（Gun.js）を採用しているため、**自前のバックエンドサーバーを用意せず GitHub Pages だけで世界中のユーザーと公開MIDI・いいね・コメントをリアルタイム共有**できます。

2. **ストリーミング風プレイヤー＆ブラウザMIDI音源再生**
   - Tone.js と `@tonejs/midi` により、サーバー変換なしでブラウザ上から直接 `.mid` / `.midi` を高音質シンセ再生します。
   - 下部固定プレイヤーバーから『再生』『いいね』『通報』『セーブ』『設定書き込み』にアクセスできます。

3. **作成者専用「設定書き込み」＆みんなに公開**
   - 書き込み可能項目：**アルバム / トラック / 年 / ジャンル / 画像 / 説明 / 作成者**
   - セキュリティ制御により、アップロードまたは作成した本人（作成者ID一致）のみが設定書き込み・編集を行えます。

4. **「.midファイルを作る」オンラインシーケンサー**
   - ブラウザ上の16ステップシーケンサーでメロディを打ち込み、試聴・`.mid` ダウンロード・そのままオンライン公開が可能です。

5. **永続ログイン＆左上3点リーダー（⋮）メニュー**
   - 『ログイン・アカウント作成』でアイコン設定とアカウント登録を行うと、永続的にログイン状態が保持されます。
   - **サインアウト**、**利用規約**、**プライバシーポリシー** はすべて左上の3点リーダー（`⋮`）内に格納されています。

## GitHub だけでオンライン公開する方法（GitHub Pages）

1. GitHub で新しいリポジトリ（例: `notevibe-midi`）を作成します。
2. この ZIP 内の以下の3ファイルをリポジトリのルートにアップロードします：
   - `index.html`
   - `style.css`
   - `app.js`
   - `README.md`
3. リポジトリの **Settings** ＞ **Pages** を開きます。
4. **Build and deployment** の **Source** で `Deploy from a branch` を選択し、Branch を `main`（フォルダは `/ (root)`）にして **Save** をクリックします。
5. 数十秒〜1分ほどで発行される `https://<あなたのユーザー名>.github.io/<リポジトリ名>/` にアクセスすると、オンライン上でそのまま動作・公開できます。
